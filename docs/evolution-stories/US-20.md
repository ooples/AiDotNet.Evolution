## User story and acceptance criteria

**Priority:** P1. **Owner:** Core scheduler maintainer. **Depends on:** US-05, US-08, US-10.

As a user running slow model-backed operators, I want independent proposal and evaluator capacity so that available workers are not starved by serial generation.

- [x] **Given** slow proposal generation and available evaluator slots, **when** pipeline mode runs, **then** separate bounded generation/evaluation queues apply backpressure, rate limits, cancellation, and resource reservations.
- [x] **Given** concurrent generation, **when** a proposal is dispatched, **then** it receives an immutable parent/context snapshot and stable identity; stateful operators remain serialized unless they explicitly support deterministic concurrent use.
- [x] **Given** a recorded deterministic schedule and external responses, **when** a run is replayed, **then** commit order and operator updates reproduce that schedule; an opportunistic mode explicitly records its different semantics.

Deliverable: an opt-in pipeline with utilization and queue metrics. Continuous evaluator dispatch already exists; the new capability is concurrent preparation/proposal work. [Current dispatch](https://github.com/ooples/AiDotNet.Evolution/blob/f0f282cf2e9027ab5278a1953493c805d6ab52ad/src/AiDotNet.Evolution/Core/EvolutionEngine.Continuous.cs).

## Local acceptance evidence

- **691 core tests pass on each** net10.0/net8.0/net471, including 30 focused pipeline cases; **55 performance-contract tests**. Coverage **92.27% line / 78.64% branch**, unchanged ratchet. Package validation and real C# output → analysis smoke pass.
- Pipeline source `9c3441d9723ed333644d991e2df9e658e4e25a74`: [576 live cases plus exact offline replay](../../benchmarks/evidence/pipeline/9c3441d/README.md), eight seed clusters with three nested timings, every response/receipt/schedule retained. Replay executes zero physical backend calls; three corrupted tapes are rejected. Tests separately verify opportunistic feedback order and settled-wave checkpoints.
- Context tests detect changed measured parent evidence even when archive version and genome IDs match. Resource tests cover known-zero unused stages, canceled/unknown work, maximum violations and deterministic admission across workers and tight retry budgets.
- PipelineConcurrent matches Batch quality and overlaps delayed callbacks faster, but ZeroLatency is slower and allocates more. Continuous quality advantage is unproven. These authored shared-host results do not establish production or competitor superiority; pipeline remains off by default.
- Default-mode regression: 132 matched before/after pairs preserve state/quality/work; nonzero allocation overhead is disclosed. A further 132-case campaign is retained but rejected for cross-build timing comparison because Windows selected a different processor group. Profiling control fix `e62b314d005faf41e7101735363b3c49af55081a` pins the group explicitly without changing scheduler code.

Resource coordination covers top-level adapters, not hidden custom ledgers; conservative reservations may leave slack. Cancellation requires cooperative backends. Arbitrary in-flight crash recovery belongs to US-21. No full-roadmap, hosted-CI or release completion is claimed.
