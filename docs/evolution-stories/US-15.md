## Acceptance

- [x] **Given** increasing resource levels, **when** successive halving runs,
  **then** selected candidates advance and valid evaluator state resumes.
- [x] **Given** one genome at different fidelities and replicates, **when** outcomes
  are recorded, **then** identities include both; low-fidelity evidence cannot
  fulfill full-fidelity evaluation or independent confirmation.
- [x] **Given** misleading early scores, **when** promotions are audited, **then**
  exploration gives late improvers a chance, while only independently confirmed
  full-fidelity outcomes can pass confirmation. Survival is not guaranteed.

Delivered: incremental model training, checksummed settled-batch checkpoints,
deterministic replay, provenance-bound model tokens, retained original evidence
and exactly-once ledger reconciliation. The optional checkpoint sink supports
coordinated pause/restart. This is one successive-halving bracket, not full
multi-bracket Hyperband or arbitrary in-flight crash recovery.

## Adversarial review

Restoration verifies ordered batch/sample/receipt history, all accounting and
confirmation constraints, latest token ownership, and exact ledger state before
continuing. Corruption, cancellation, receipt truncation and sink failure/mutation
are covered. Only the needed receipt-tombstone lookup was added to the current
ledger; importing the older ledger wholesale would remove newer budget safeguards.

Additional fixes reject negative quality/costs, balanced negative receipts and
negative MSE in analysis; a -1 MSE previously reached division by zero. Invalid
runs retain worst-support penalties. Regression-model tokens now require exactly
the declared fields; omitted replicate-zero values, duplicate fields and unknown
fields cannot be silently accepted. State version is `regression-gd-state-v2-strict-fields`.
