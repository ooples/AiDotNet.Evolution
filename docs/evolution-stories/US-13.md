# US-13: Supply typed search spaces and useful operators

Issue: [#31](https://github.com/ooples/AiDotNet.Evolution/issues/31).
This integrates the reviewed implementation from PR55 at
`5bf77a04dea6b8d99840a15a69953efe1110826d` with the current US-03–08/runtime stack,
without replacing newer accounting, noise or portfolio implementations.

As a .NET developer, I want typed parameters and useful operators so that I can
optimize an application without writing every genome and mutation detail.

## Acceptance

- [x] **Given** real, integer, enum, logarithmic and conditional parameters,
  **when** a space is built, **then** domains validate, initial candidates sample
  deterministically, and inactive values canonicalize consistently.
- [x] **Given** a supported genome, **when** mutation, crossover, restart or explicit
  budgeted local refinement is selected, **then** candidates remain valid and
  independently owned, with reproducible streams and charged refinement work.
- [x] **Given** supported continuous domains, **when** optional diagonal CMA is
  enabled, **then** covariance/step state survives checkpoint restoration and
  quality is compared with simpler methods at matched evaluator-call budgets.

Mutation remains the default. Uniform/adaptive mixed presets use the same three
operators. Local refinement requires an explicit objective, version and ledger.
The diagonal emitter is not full-covariance CMA-ME and remains opt-in.

## Adversarial fixes and measurable before/after

| Contract | Before integration | After |
|---|---|---|
| Adjacent log bounds near 1e100, 1e-100, 1e300 | Equal rounded logs permit 0/0 normalization | All three endpoint regression cases are finite and exact |
| Real upper endpoints in [-1e100,1], [-1e300,1e-100], [-1,1e-100] | Normalized 1 decodes to 0 | All three decode to the declared maximum exactly |
| Enum API | Manual categorical strings | Declared-name domain factory and typed accessor; numeric strings, wrong case and undeclared flags rejected |
| Changed mapping compatibility | Old schema could silently reinterpret coordinates | Explicit log-v3 and real-v2 fingerprints reject old incompatible payloads |
| Story test coverage on this stack | Preset/domain suites absent | 51 added cases per core target; 153 additional passing executions |

Integer and categorical fingerprints remain compatible. Real/log fingerprints
change deliberately; no compatibility forwarding is supplied. Narrow-domain
roundtrips, conditional activation, owned candidates, preset catalogs, wrong
directions, worker-independent replay and exact checkpoint continuation are tested.
