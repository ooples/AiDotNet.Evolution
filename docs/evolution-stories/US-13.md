## Story-owned implementation and adversarial findings

The shared foundation supplies immutable domains/genomes, canonical inactive values, sampling/features/codec,
mutation/crossover/restart, explicitly metered local refinement and optional checkpointed diagonal CMA. This branch adds
`EvolutionSearchPresets.Create`: explicit Mutation, UniformMixed, AdaptiveMixed and DiagonalCma choices with fresh
owned operator state. Mutation remains the default; crossover requires engine inspirations and refinement still
requires an explicit objective/version/shared ledger. Unsupported CMA domains fail before search.

The audit found three reproducible NaN failures for adjacent positive bounds near 1e100, 1e-100 and 1e300: distinct
doubles had equal rounded logarithms, causing zero divided by zero in normalization. Narrow collapsed log spans now
use bounded linear interpolation/normalization. All logarithmic schema fingerprints carry an explicit version tag,
so old logarithmic genomes/checkpoints are rejected instead of silently reinterpreted. Six compatibility cases verify
that real/integer/categorical v1 identities remain compatible while old log identities are rejected. The tag does not
depend on runtime-specific rounding. [Domain and preset contract](../TYPED_SEARCH_SPACES.md).

Producer-declared reused measurements cannot train CMA as fresh samples; that prior adversarial finding is now fixed
through the integrated US-08 dependency, with its regression suite retained. Normal/adaptive preset state and exact
resumed trajectories are tested across worker counts. Existing custom-genome APIs and direct operator constructors remain.
