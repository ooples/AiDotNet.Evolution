## History

The first implementation, PR #54, merged into `feat/evolution-us-07` and never reached `main`. Its
workflow, gate script and documents were absent from `main`. This port brings them to `main` and
rebuilds the gate on the registration and analysis that `main` now has (V1-05,
`campaign_registration.py`). #54's own protocol schema and Hoeffding statistics are not ported;
the PR that ported it lists each conflict and how #121/#122 resolved it.

## Status

| Criterion | State |
| --- | --- |
| Fast deterministic checks on PRs; competitor campaigns only on scheduled or budgeted jobs | Implemented: claim gate on every PR; CPU comparison on schedule or dispatch only; the paid campaign stays on the campaign machine behind the runner's budget confirmation |
| Release report names benchmark, task set, model, budget and hardware, and publishes the complete bundle | Implemented: assessment `report` block; bundle uploaded and attached to the GitHub release |
| >= 1.10x geometric-mean speedup at equal search cost, 95%-level decision, independent correctness | Implemented: Holm-corrected strict superiority at the registered familywise alpha, 1.10x geomean floor on `speedup` endpoints, shared-budget check per row. | Metrics table (family x config wins, AlphaEvolve match/beat) | Open: needs the #122 campaign |
