## Acceptance evidence

- [x] **Given** the same benchmark and resource budget, **when** Uniform, Ratio, Curiosity, and Double selection are compared, **then** results show quality, diversity, success, and cost for each task family. The registered local numeric, symbolic-program and CPU-kernel study supplies every row; it does not claim unrestricted LLM-program coverage.
- [x] **Given** islands, migration, novelty filtering, calibration, archive growth, and continuous dispatch, **when** each is enabled or removed, **then** its contribution and important interactions are measured against the same baseline. The 19-condition matrix includes removals, migration conditional on islands, calibration × growth and islands × continuous interactions. Higher-order interactions are outside this fixed design.
- [x] **Given** a better configuration on development tasks, **when** it is proposed as a default, **then** its benefit is confirmed on untouched tasks without changing the evaluation criteria. The gate ran on different tasks and seeds. No nominee cleared it, so **no changed default is proposed**; baseline presets are retained, not declared optimal.

Deliverable: frozen ablation campaigns and evidence-governed presets for the documented local workloads. The program workload is a bounded expression grammar. Applying its preset to unrestricted generated programs, or claiming production kernel speedups, requires additional workload-specific evidence and is not established here.
