## User story and acceptance criteria

**Priority:** P1, experimental default off. **Owner:** Search maintainer; model implementations in AiDotNet/adapter package.
**Depends on:** US-05, US-08, US-13.

As a user with expensive evaluations, I want a learned approximation to identify promising candidates so that fewer full evaluations are wasted.

- [x] **Given** measured candidate outcomes, **when** a surrogate ranks a proposal pool, **then** it records predicted quality, uncertainty, model version, and an explicit exploration allocation; predictions never masquerade as validated archive fitness.
- [x] **Given** weak calibration, unfamiliar candidates, or insufficient training data, **when** ranking becomes unreliable, **then** selection falls back to an established non-surrogate policy and continues collecting representative measurements.
- [x] **Given** the same total cost cap, **when** surrogate and ordinary search are compared, **then** training, inference, and rejected-proposal costs are included and every promoted winner receives true evaluation.

Deliverable: an optional prediction/acquisition contract and a first numeric implementation. Support multiple
prediction backends without making the generic engine depend on a model library.

These checks establish the implemented contracts, not universal representativeness of a finite random sample,
formal uncertainty coverage or a deployment-quality improvement.

## Acceptance evidence

1. `EvolutionSurrogateSelector<T>` returns a typed unvalidated prediction record, acquisition/fallback reason,
   complete valid prediction pool, model/training identity, exploration probability and operation identity.
   `IEvolutionSurrogateDiagnosticModel` adds a bounded detached validation report, retained for both accepted
   ranking and unreliable-model fallback. Original sample IDs may not overlap even under different reuse scope
   keys; original-sample metadata contributes to the training fingerprint. Historical semantic identity is bumped.
2. `ValidatedNearestNeighborTrainer` owns detached features and splits distinct genome groups into fitting,
   residual-calibration and separate validation partitions. Replicates cannot leak across these partitions.
   Insufficient distinct groups, excess error, inadequate empirical coverage and unfamiliar candidates cause
   fallback. An adversarial test changes only validation labels: its perfect calibration radius is correctly
   rejected. Uniform fallback and explicit probabilistic exploration still request true measurements.
3. The [pinned pilot](../../benchmarks/evidence/surrogates/c770896/README.md) includes all 240 runs:
   two authored objectives × four methods × ten paired seeds × three evaluator tariffs. All setup, proposal,
   fitting/calibration/validation, inference and true-evaluation tariffs count against the same total cap within
   each scenario. Full replay is byte-identical. All winners are true measurements, with no unknown charges,
   dropped receipts, outstanding reservations or overruns. All 18 paired intervals include zero; unfavorable
   means/tails remain in the complete raw evidence. This is not evidence that the surrogate beats competitors.
