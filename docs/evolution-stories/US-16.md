All implementation is in AiDotNet.Evolution; newer resource-ledger and correctness contracts are preserved.

As a user, I want searches to escape unproductive regions without losing their best measured results.

## Acceptance

- [x] **Given** different recent valid gains and diversity, **when** allocation updates,
  **then** productive islands receive more proposals while every complete epoch preserves an exploration floor.
- [x] **Given** stagnation over a declared window, **when** restart exploration begins,
  **then** its proposals are bounded and measured archive elites and ordinary child learning are preserved.
- [x] **Given** heterogeneous children and pending outcomes, **when** a checkpoint is restored,
  **then** policy state, membership, migration history and attribution reproduce, or incompatible state is rejected.

Fixed membership supports 1–64 islands; restarts are bounded independent exploration, not hard covariance resets.
Dynamic membership is not included. Independent deployment confirmation is still required for selected results.

## Adversarial review and fixes

- Strict `adaptive-islands-v2-strict-state` checkpoint identity rejects older states. Every object field must
  occur exactly once; missing default-valued scalars, duplicate fields and unknown fields fail before child restore.
  Prior behavior explicitly accepted omitted empty-state counters; that compatibility was intentionally rejected.
- Complete child preflight and existing semantic/accounting checks remain. A rejecting child can mutate its own
  state before failing; discard that wrapper rather than retrying it. Storage must be trusted.
- New tests exercise shared proposal/evaluation budgets through normal/restart phases and pending checkpoint
  restore. Insufficient remaining budget rejects dispatch without overspending or orphaned attribution.
- Evidence now reconciles summary fields against raw measurements, recomputes objectives and best-quality curves,
  and checks unique identities, receipts, reservation clearance and timing. Hash agreement alone is insufficient.
- The v2 benchmark rotates method order, accounts eight warmups separately and retains whole-run elapsed time
  and quality-versus-time observations. Timing never drives deterministic policy choices.
