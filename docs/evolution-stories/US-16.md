## User story and acceptance evidence

**Priority:** P1. **Owner:** Search maintainer. **Depends on:** US-05, US-07, US-08.

As a user, I want search to escape unproductive regions so that a long run continues exploring alternatives.

- **Given** islands with different recent valid gains and diversity, **when** resource allocation updates, **then** productive islands receive more proposals while a minimum budget preserves exploration.
- **Given** stagnation over a declared window, **when** a restart triggers, **then** the policy preserves verified elites and seeds a bounded new exploration phase without silently discarding the best result.
- **Given** heterogeneous island operators or membership changes, **when** a checkpoint is restored, **then** policy state, island identities, migration history, and allocation decisions are restored or the incompatible checkpoint is rejected.

1. **Allocation:** `AdaptiveIslandSearch<TGenome>` gives every island a hard floor in each complete epoch, then weights remaining proposals by bounded recent fresh parent gains and new-cell diversity. The deterministic productive-versus-stalled test allocates more than twice as many proposals to the productive arm while checking every completed epoch's floor. Invalid, infeasible, mismatched-direction and declared reused measurements receive no fresh credit.
2. **Restarts:** a declared stagnation window schedules a bounded independent exploration phase. Tests prove slot caps, pending-outcome routing and preservation of the measured archive best even when exploration is worse. Archives and normal child learning are not cleared. This is an explicit soft exploration restart, not a hard covariance reset; scheduled phases are distinguished from completed proposals/outcomes.
3. **Persistence:** the checkpoint fingerprints ordered membership, all policy settings and every child identity/version. It restores bounded rewards, epoch counts, pending attribution, restart phases, recent decisions and child state. Engine tests verify identical full/resumed state hashes with heterogeneous stateful children and migration, plus identical results across worker counts in batch/continuous dispatch. Corrupt policy graphs and incompatible membership are rejected before child restore; if an individual child rejects, discard that wrapper before retrying.

[Usage, contracts and limits](../ADAPTIVE_ISLANDS.md). The fixed pool supports 1–64 independently owned island strategies. Dynamic creation remains the report's explicitly later option.
