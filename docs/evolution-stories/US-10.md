## Product optimization and adversarial fixes

A measured archive snapshot allocation hotspot was traced to redundant sorting arrays. Snapshot construction now
sorts its privately owned bounded copy in place and scans for the best entry. It does not cache mutable archive state,
change scalar ordering, mutate source arrays, or remove duplicate-cell/metadata validation. Regression tests cover
both optimization directions, ties, source order, detached snapshots, empty archives and duplicate cells.

The profiler also now:

- Normalizes each attempt before calculating allocation medians or per-iteration extrema, fixing misleading ratios
  of aggregated values when measured iteration counts differ.
- Checks derived throughput, bounded iteration arithmetic and finite delay extrema containing the mean.
- Rejects unplanned, unjustified or excessive contention retries while preserving failure evidence.
- Verifies both core and profiler assembly source revisions.
- Stops labeling Linux per-thread schedstat as process-wide CPU; the optional fine-resolution field is unavailable.
- Preserves complete compressed before/after reports locally in the repository, with hashes and a comparison
  that checks matching controls/plans, exact search state and quality. No release publication is needed.

Historical published table columns were regenerated with corrected arithmetic; their raw measurements were not rewritten.
